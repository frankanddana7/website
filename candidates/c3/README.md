# Studio Subasio — candidate c3

Modern, rounded style: pill nav/buttons, soft shadows, chunky headings.
The home page floats a white card over a very slow, low-contrast drifting
stone gradient (pure CSS, ~48s cycle, stops for reduced motion). Interior
pages stay plain white so the artwork is never competing with anything.

"Studio Subasio" and the two artist names are placeholders — swap them.

## To add an image
Drop your image file into `images/`, then open the relevant project page
(e.g. `paintings.html`), copy one whole `<!-- IMAGE BLOCK -->...<!-- END
IMAGE BLOCK -->` section, paste it below the last one, and change the
`src`, `alt`, title, and caption text. No CSS edits needed.
