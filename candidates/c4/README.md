# Candidate c4 — Floating Boxes

Clean, timeless, editorial. White page, white boxes, thin stone hairline
borders, small (0–4px) corner radius, restrained shadow. Georgia/serif
headings over plain sans body text. One column everywhere on mobile; the
home page grid becomes 2 then 3 columns as the screen widens. No JS.

"Studio Subasio" is a placeholder name — swap it (and "Nome Uno" / "Nome Due")
for the real studio and artist names everywhere it appears.

## Adding an image
Open any project page (e.g. `paintings.html`), copy one whole
`<!-- IMAGE BLOCK -->...<!-- END IMAGE BLOCK -->` comment section, paste it
above `</div>` before `</main>`, then edit the `src`, `alt`, and the two
lines of text. Drop your image file into `images/` first.
