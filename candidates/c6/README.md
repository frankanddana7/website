# Studio Subasio — candidate c6

Clean, timeless, floating-box style: white boxes on white, thin stone
hairlines, restrained shadows, serif headings over plain sans body text.
"Studio Subasio" is a placeholder studio name — swap it everywhere before
launch. The one interactive touch: on the home page, hovering a project box
(desktop only) swaps a large preview image into the panel beside it and dims
the other boxes; on phones each box just shows its image inline instead. No
JavaScript is used anywhere — the whole effect is CSS.

## Adding an image
Drop your photo into `images/`, then open the relevant project page and copy
one whole `<!-- IMAGE BLOCK -->...<!-- END IMAGE BLOCK -->` chunk in
`.pieces`. Change `src` to your new file, update the `alt` text, title and
description. Nothing else needs to change.
