## Adding a new image
Drop your file (e.g. `piece9.jpg`) into `images/`. Open the relevant project
page, copy one whole block between `<!-- IMAGE BLOCK -->` and
`<!-- END IMAGE BLOCK -->`, paste it below the last one, then change the
`src`, `alt`, `<h3>` title, description and the small `piece-tag` line.
